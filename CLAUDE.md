# Puro Pockets: instrucciones para Claude Code

Antes de implementar cualquier cosa, lee en este orden:

1. `.specify/memory/constitution.md`: reglas de negocio (`RN-xx`) y gobernanza.
2. `docs/plan-tecnico.md`: stack, arquitectura y esquema de datos.
3. `HITOS.md`: alcance y orden de los hitos.

- Cita las reglas por su identificador (`RN-xx`); no las reescribas ni las cambies.
- Si dos documentos se contradicen o algo no está claro, detente y pregunta (ver la gobernanza).
- `docs/origen/` es material archivado, no fuente de verdad.
